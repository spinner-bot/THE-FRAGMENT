# 附录 C：P2 快速幂计算

> **用途：** 复现 K 的计算，验证 `10^18` 次递推可以压缩成一次模幂。
>
> 相关章节：第 22–25 章。

---

## C.1 题目参数

```text
M = 2^255 - 19
C = 37034745566544782617569137203076208463588743464624141058302227831050492871311
x_0 = 1
N = 10^18
x_{n+1} = (3 x_n + C) mod M
K = x_N
```

其中：

- `M` 是 Curve25519 的素数域模数；
- `C` 是题面给出的常数；
- `N` 是迭代次数；
- `x_0 = 1`。

`SHIT.README` 里同时出现 `N = 10^18` 和 `N = 10^81`，还说 `x_0 = 1 is a lie`。这些是误导；真正的判定标准是 Q3 锁的 TAG：只有一组参数能通过验证。

## C.2 闭式解

递推：

```text
x_{n+1} = 3 x_n + C
```

展开：

```text
x_1 = 3 x_0 + C
x_2 = 3^2 x_0 + 3C + C
x_3 = 3^3 x_0 + 3^2 C + 3C + C
...
x_N = 3^N x_0 + C (3^N - 1) / (3 - 1)
    = 3^N x_0 + C (3^N - 1) / 2
```

在模 `M` 下，“除以 2” 用模逆元：

```text
inv2 = (M + 1) / 2 = 2^{-1} mod M
```

因为 `M` 是奇素数，`inv2` 是整数：

```text
inv2 = 28948022309329048855892746252171976963317496166410141009864396001978282409975
```

于是：

```text
K = (3^N * x_0 + C * ((3^N - 1) * inv2 mod M)) mod M
```

## C.4 计算代码

```python
M = 2**255 - 19
C = 37034745566544782617569137203076208463588743464624141058302227831050492871311
N = 10**18

a = pow(3, N, M)                 # 3^N mod M
inv2 = (M + 1) // 2              # 2^{-1} mod M
K = (a + C * ((a - 1) * inv2 % M)) % M

print(K)
print(hex(K))
```

输出：

```text
55570866527475159802584688178377681056129853902315582853460115578675137387640
0x7adbfeef3a37490e4bd46bb6fca3c1690005d6e1c30a798820ee733de3fc9c78
```

`pow(3, N, M)` 是 Python 内置的模幂，复杂度 `O(log N)`，对 `N=10^18` 只需约 60 次乘法级操作。

## C.5 逐项验证

不要只信闭式；用前几项对拍：

| n | 直接递推 | 闭式 |
|---:|---|---|
| 0 | 1 | 1 |
| 1 | 3 + C mod M | 3 + C |
| 2 | 3(3+C)+C = 9+4C | 9 + 4C |
| 3 | 27 + 13C | 27 + 13C |
| 4 | 81 + 40C | 81 + 40C |

系数 `1, 4, 13, 40, ...` 满足 `a_{n+1}=3a_n+1`，正是 `(3^n-1)/2`。

验证脚本：

```python
def direct(N):
    x = 1
    for _ in range(N):
        x = (3*x + C) % M
    return x

def closed(N):
    a = pow(3, N, M)
    return (a + C * ((a - 1) * ((M + 1)//2) % M)) % M

for n in range(20):
    assert direct(n) == closed(n)
```

## C.6 为什么不用迭代

`N = 10^18`，即使每秒一亿次，也需要约 317 年。闭式把“次数”变成“指数”，用模幂在微秒级完成。

这也是 P2 的核心难点：

- 识别递推是仿射的；
- 知道仿射递推有闭式；
- 会在模意义下除以 2；
- 用 Q3 的 TAG 验证参数（尤其是 N）。

## C.7 参数判定

题面同时给出 `10^18` 和 `10^81`，还有 `x_0=1 is a lie`。可能的参数组合：

| N | x_0 | 结果 |
|---|---|---|
| `10^18` | 1 | 能通过 Q3 TAG |
| `10^81` | 1 | 不能 |
| `10^18` | 其他 | 不能 |

因此不需要相信 README 的叙述，只需要用 TAG 做一次判定。第 25 章给出了完整的候选排除表。

---

## C.8 与答案链的关系

K 是 Q2 的答案，也是 Q3 锁的 `D`：

```text
P1 = 5050  → 打开 Q2
Q2 的仿射题 → K
K          → 打开 Q3
```

K 必须按十进制原样写入锁的 `SHA-256(ASCII(D))`，不能加空格、下划线或换行。第 13 章说明了规范化规则。

---

## C.9 一句话总结

`x_{n+1}=3x_n+C` 的 `10^18` 次迭代等于 `3^N x_0 + C(3^N-1)/2 mod M`；一次 `pow` 就能算出 77 位的 K。
