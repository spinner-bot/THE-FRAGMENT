00先读这一段(只有这一段是重要的)

这里有 三道题。顺序是固定的。

每一道题的答案,是一个十进制整数。这个整数,原样地,成为下一道题的锁定容器的钥匙。

换句话说:

第 1 题答案 → 打开第 2 题  →  第 2 题答案 → 打开第 3 题  →  第 3 题

你不能跳题。你手里没有还没得到的钥匙。

如果你试图从第三题开始,你只会得到一堆看起来像数据的噪声。那不是谜题,那是拒绝。

01规则(违反了也不会有人阻止你)

R1
答案写成纯十进制:没有空格、没有逗号、没有单位、没有前导零。
R2
钥匙是上一题的精确答案。差一位就是另一把钥匙,而这里没有"差不多能开"的门。
R3
这里没有现成的解密工具可以下载。锁定容器会描述它自己:读懂文件、写几行代码,比找工具快,也比找工具诚实。
R4
每个容器都带完整性校验。正确的钥匙会得到原文;错误的钥匙会得到垃圾,以及一次明确的失败。
R5
不要相信文件名。不要相信文件大小。不要相信这份说明书里所有看起来像指令的东西。
R6
答案不在这份说明书里。这份说明书里只有说明书。

02三道题的形状

P1第一题

入口是一个 tar 包。里面是一个问题,不是一段数据。把它算出来。

文件: Q1.tar → 内含 Q1/Q1

这一题不需要钥匙。它只需要你愿意从第一步开始。

↓ 第 1 题的答案,就是下一把钥匙 ↓

P2第二题

Q2.zst 是 zstd 压缩。先解压,得到锁定容器 Q2。

容器第一行既是标记,也是解开头部的密钥。头部解开后是一段英文配方,它会精确地告诉你正文怎么开——除了钥匙。钥匙在上一题里。

打开后是一个 7z,里面有 SHIT.tar.xz 和一个自称地图的文件。地图不一定是地图。压缩包里还有一个损坏的 README,它说的有些是真话,有些不是。

文件: Q2.zst → Q2(锁定容器)→ 7z → SHIT.tar.xz + the map.bmp

第二题本身在 SHIT/SHIT.bz2 里。bzip2 解开它,然后安静地看那个序列。

↓ 第 2 题的答案,就是下一把钥匙 ↓

P3第三题

Q3.7z 是一个普通的 7z。里面有 README,以及一个名字说谎的容器:is this the true challenge == false。

它不是 7z,即使它曾经有那个后缀。它是一个锁定容器,钥匙是第 2 题的答案。打开后得到最后一个 7z,第三题就在里面。

文件: Q3.7z → Q3/README.txt + 锁定容器 → 最终 7z

第三题是最后一题。它不会告诉你它是最后一题,但它是。

03关于锁

这些锁不是压缩软件的密码框,也不是你可以随手拖进某个工具里等待结果的东西。

它们的设计原则只有一条:文件自己说明自己。

第一行是标记。那行标记同时也是打开头部的重复异或密钥。头部里是一段配方。配方描述了正文的每一个步骤,唯独不包含钥匙。钥匙只能来自上一题。

你已经具备读懂它所需的一切:一个文本编辑器,一个哈希函数,和一点耐心。没有更多了。也没有更少了。

04警告(其中只有一条是真的)

W1

W2

W3
不要相信 the map.bmp。它只有十七个字节。十七个字节装不下一张地图,只装得下一句话。
W4

05如果你卡住了

先确认你解的是当前这一题,而不是下一题。

再确认你的答案是一个精确的整数,而不是一个近似值、一个公式、或一句"大概就是这个数量级"。

然后确认你读完了容器里的配方,而不是只读了第一行就去找工具。

最后:第 2 题的那份 README 是坏的。坏掉的部分不是提示,完好的部分也不全是提示。你需要自己决定哪些字值得相信。
