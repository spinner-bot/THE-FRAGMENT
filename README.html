三题说明书

一份说明书。不是一份答案。

这两者经常被混淆。混淆它们的人通常停在第一题。

本行是一条用于填充的句子。它不指向任何内容,也不指向它自己,因为指向自己需要先有一个自己。它没有。它继续。它没有继续。

00先读这一段(只有这一段是重要的)

这里有 三道题。顺序是固定的。

每一道题的答案,是一个十进制整数。这个整数,原样地,成为下一道题的锁定容器的钥匙。

换句话说:

第 1 题答案 → 打开第 2 题  →  第 2 题答案 → 打开第 3 题  →  第 3 题

你不能跳题。你手里没有还没得到的钥匙。

如果你试图从第三题开始,你只会得到一堆看起来像数据的东西。那不是谜题,那是拒绝。

01规则(违反了也不会有人阻止你)

R1
答案写成纯十进制:没有空格、没有逗号、没有单位、没有前导零。
R2
钥匙是上一题的精确答案。差一位就是另一把钥匙,而这里没有"差不多能开"的门。
R3
这里没有现成的解密工具可以下载。锁定容器会描述它自己:读懂它、写几行代码,比找工具快,也比找工具诚实。
R4
每个容器都带完整性校验。正确的钥匙会得到原文;错误的钥匙会得到垃圾,以及一次明确的失败。
R5
不要相信名字。不要相信大小。不要相信这份说明书里所有看起来像指令的东西。
R6
答案不在这份说明书里。这份说明书里只有说明书。

02三道题的形状

P1第一题

入口。没有锁,没有钥匙,没有前置条件。

它只要求一件你已经会做、但可能不愿意做的事:从最前面开始。

算出一个整数。把它留下,不要修改它。

↓ 第 1 题的答案,就是下一把钥匙 ↓

P2第二题

这一题被锁住了。锁不接受猜测,只接受第 1 题的完整答案。

打开之后,你会遇到一份可疑的说明和一道需要安静思考的题。说明不保证诚实,题目不保证友好。

答案仍然是一个整数。

↓ 第 2 题的答案,就是下一把钥匙 ↓

P3第三题

最后一题。它的锁只认第 2 题的答案。

它不会告诉你它是最后一题。但它是。

到这里,捷径已经全部用完了。

03关于锁

这些锁不是压缩软件的密码框,也不是你可以随手拖进某个工具里等待结果的东西。

它们的设计原则只有一条:容器自己说明自己。

它不会把方法藏起来,也不会把钥匙交给你。方法需要你自己读出来,钥匙只能来自上一题。

你已经具备读懂它所需的一切:一个文本编辑器,一个哈希函数,和一点耐心。没有更多了。也没有更少了。

CONFIDENCE11%

04警告(其中只有一条是真的)

W1
不要寻找任何自称"答案"的东西。你找到的可能不是答案,而是一段专门写给你的话。
W2
不要跳过第一题。你跳过的每一步,都会在最后一题里重新出现一次。
W3
不要因为某个名字看起来像提示就相信它。名字是成本最低的谎言。
W4
如果你在一个文件里读到"答案是钥匙",请记住:这句话是对的,但"钥匙"不等于"答案",而"答案"也不等于"你现在需要的那个答案"。
W5
本说明书共 3 页。你正在读第 7 页。

THE FIRST LOCK IS NOT THE FIRST LOCK. THE SECOND LOCK IS THE FIRST LOCK.

有人把这句话数了三遍,得到了三个不同的长度。三个长度都正确。数数的人不在场。

倒着读也是同样的意思(并不是)

一只鸟落在一根不存在的电线上,然后飞走了。电线没有留下痕迹,鸟也没有。

这段文字与上一段之间的距离,正好等于下一段的长度。

05如果你卡住了

先确认你解的是当前这一题,而不是下一题。

再确认你的答案是一个精确的整数,而不是一个近似值、一个公式、或一句"大概就是这个数量级"。

然后确认你读完了容器里的全部说明,而不是只读了第一行就去找工具。

最后:第二题给你的说明不会完全可靠。哪些字值得相信,需要你自己决定。
